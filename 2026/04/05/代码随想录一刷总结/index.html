代码随想录一刷总结

发表于2026-04-05|更新于2026-05-14|算法与C++
|总字数:913|阅读时长:2分钟|浏览量:

两个月前，当我报名代码随想录算法训练营时，我还是一个只会冒泡排序的算法小白。刚开始我的目的就是“花钱买自律”，让我能够坚持打卡下去。而现在，我终于可以说：我确实做到了。 两个月的时间，每天雷打不动地将打卡内容做完，即使有时候已经过了零点。

0x01 蜕变：从战战兢兢到输出倒逼输入

从刚开始听到“要每天写博客”时的战战兢兢，到后面觉得写博客只是一件稀松平常的事，这是一个巨大的心态转变。

不过，这部分程度上依赖于 CSDN 现成的平台。刚开始我其实想自己搭一个专属的个人博客，但是在 GitHub 上建了库、选了模板后，还没来得及完全按照自己的想法精装修，打卡就开始了。为了让启动的阻力小一点，我就先开了一个 CSDN 号开始记录。

不得不说，写好博客是非常消耗精力的。 如何把知识内化之后用自己的方式讲述出来，并且加上合适的示意图？这些都需要对分享的内容有深入的理解，以及让“新手小白也能看懂”的耐心。

反思：
我目前写的博客大多都还在刻板地复述知识点，甚至更多停留在“自己能够理解”，而非“所有人都能理解”的程度。特别是开学以后事情变多，博客基本上没有了自己深度的内容输出，只是贴了一下代码。

这也是我希望在之后的学习中能够改进的点。但无论如何，这次训练营让我真正开始动手写博客，这个从 0 到 1 的过程本身就已经十分可贵了。

0x02 收获：算法初识

这两个月的旅途确实让我学习到了很多硬核知识：

从二分查找到栈和队列，再到贪心算法、动态规划，到最后的图论等等。每个专题都有很好的文字版和视频讲解，题目的设置循序渐进，让我可以由浅入深去掌握一个算法。

并且，因为我大一上学的是 C 语言，所以我是从开营起才开始用 C++ 写代码的。这次训练营不仅练了算法，也给了我一个极好的机会去熟悉 C++ 的代码风格、格式规范和底层语法，真可谓一举多得！

0x03 坚持：深夜十二点的打卡，痛并快乐着

最后的这半个月坚持下来很难。因为最近学校里的事情很多，大多数时候都是在晚上十点之后才能抽出时间来打卡。

每次累得不行还要去开电脑打卡时，都有一点“命很苦”的感觉（bushi 🤣），但是放弃的念头从来没有出现过。一直坚持打卡，也是最近在繁忙学习生活中最能带给我成就感的事情。

0x04 终章，也是新起点

虽然训练营结束了，题目也都刷完了，但是距离真正“吃透”里面的内容还有一段距离。不管是那些一刷没深入掌握的知识点，抑或是未来可能会遗忘的算法，我相信我和《代码随想录》还会经常见面的。

感谢卡哥做出了如此高质量的开源学习资料！
我们后会有期！
终于能好好休息一下了（瘫）
