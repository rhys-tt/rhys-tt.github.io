  1. ls 的 -l 选项（flag）作用是什么？运行 ls -l / 并观察输出。每一行最前面的 10 个字符分别代表什么？（提示：man ls）

ls -l 会以 长格式（long listing） 列出目录内容，不仅显示文件名，还会输出文件的详细元数据，包括权限、所有者、大小、修改时间等信息。

运行 ls -l / 后，每一行开头的 10 个字符格式为：-rwxr-xr-x（示例），拆成 4 部分理解：

位置 含义 说明
第 1 位 文件类型 -普通文件 /d目录 /l符号链接 /b块设备 /c字符设备 /p管道
第 2-4 位 所有者权限 r读 /w写 /x执行（-表示无权限）
第 5-7 位 所属组权限 同上，是文件所属用户组的权限
第 8-10 位 其他用户权限 同上，是系统中其他所有用户的权限

三种引号的区别：

引号类型 解析规则 特殊字符处理
单引号' ' 完全字面解析 所有字符都失去特殊含义，包括$、!、\、换行
双引号" " 部分解析 会解析$（变量 / 命令替换）、\（转义）、```，但!在非交互式 Shell 中会被当作普通字符
ANSI 引号$' ' 支持转义序列 支持\n（换行）、\t（制表符）、\xHH（十六进制）等 ANSI 转义，同时保留单引号的字面性
  1. Shell 有三条标准流：stdin（0）、stdout（1）、stderr（2）。运行 ls /nonexistent /tmp ，把 stdout 和 stderr 分别重定向到两个文件。你将如何把两者都重定向到同一个文件？参见 Redirections。

三个标准流的含义：

  • stdin：标准输入，文件描述符 0
  • stdout：标准输出，文件描述符 1
  • stderr：标准错误，文件描述符 2

分别定向到两个文件：

  • > stdout.txt：将 stdout（描述符 1）重定向到 stdout.txt
  • 2> stderr.txt：将 stderr（描述符 2）重定向到 stderr.txt

同时重定向到同一个文件:

  • > combined.txt: 把标准输出（1）重定向到 combined.txt
  • 2>: 重定向标准错误
  • &1指向 1 的位置（不是文件，是文件描述符）

  1. 为什么 cd 必须是 Shell 内建命令，而不能是独立程序？（提示：想想子进程能影响和不能影响父进程的哪些状态。）

当执行一个外部程序时，Shell 会创建一个子进程来运行它。子进程的工作目录是独立的，无法修改父进程（Shell）的工作目录。如果 cd 是外部程序，它修改的只是自己的工作目录，执行完就退出了，对 Shell 本身毫无影响。所以，cd必须作为Shell内建命令，直接运行在Shell进程内部，才能修改Shell` 的当前工作目录。

解析这条命令：

  • ssh myserver: 连到服务器 myserver
  • journalctl -u sshd -b-1: 查看上一次开机（-b-1）以来的sshd日志
  • grep "Disconnected from"：只抓包含 “Disconnected from”（断开连接）的日志
  • sed -E 's/.*Disconnected from .* user (.*) [^ ]+ port.*/\1/': 将用户名提取出来，靠(.*)匹配
  • sort | uniq -c: 统计每个用户断开了多少次
  • sort -nk1,1 | tail -n10: 按次数从小到大排序，取断开最多的前十
  • awk '{print $2}': 只要输出用户名，不要次数
  • paste -sd,: 把每行用逗号连起来
    总体思路：连上服务器 → 抓 SSH 断开日志 → 提取用户名 → 统计次数 → 取断开最多的 10 个用户 → 用逗号拼成一行输出
